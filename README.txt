This website gives a brief explanation of 3 different types of bugs, along with 3 different species of each bug. 
Every species has an image attached, within a flexbox so that it fits nicely inside the browser. These flexboxes can also
change location and size with the size of the media, in particular they will go into a column orientation when the width of
the browser becomes less than 500 pixels. 
One of the spider species has a video embedded within the flexbox, as the behavior of this spider is the most interesting part
about it. Navigating between the pages is easy, with a nav bar at the top of each page which links to each other page.
